

I asked my audiophile dad for his favourite music of all time, given we spend a lot of time talking about music. To my surprise he gave me a 30GB USB stick completely full of music, all organised into 40-80 minute mixes.

Not only did I want to listen to this music but I also wanted to share it with my friends: I always thought it was criminal such a prolific curator didn't have an audience. However, there were two issues with this:

* I didn't really know what I was listening to as none of the files had any metadata. Each mix had it's own folder, and each track within each folder was unnammed ("Track 01", "Track 02" etc). The only way to actually know what you're listening to was a ~50 page word document which matches track numbers to metadata.

* It was not in an easy to listen to format. If I wanted to share any of these curations with people, a bunch of mp4 files in a large collection of folders was not going to cut it.
