

I asked my audiophile dad for his favourite music of all time, given we spend a lot of time talking about music. To my surprise he gave me a 30GB USB stick completely full of music, all organised into 40-80 minute mixes (I later found out this was the greatest hits of the 1600 hits he compiled).

Not only did I want to listen to this music but I also wanted to share it with my friends: I always thought it was criminal such a prolific curator didn't have an audience. However, there were two issues with this:

* I didn't really know what I was listening to as none of the files had any metadata. Each mix had it's own folder, and each track within each folder was unnammed ("Track 01", "Track 02" etc). The only way to actually know what you're listening to was a ~50 page word document which matches track numbers to metadata.

* It was not in an easy to listen to format. If I wanted to share any of these curations with people, a bunch of mp4 files in a large collection of folders was not going to cut it.

With these two issues I action the following objectives across each of the scripts in this repo:

1. Transform the Microsoft Word documentation into a structerd, tidy dataset.
2. Create a dataframe which links the clean music documentation with raw audio files.
3. Actually apply the master music documentation to the audio files. For the purposes of sharing this music with others, I also construct a .txt file tracklist for each mix as well as singular concatenated .mp4 file which can be uploade to mix cloud.

If you are interested in seeing the fruits of this project, you can listen to the produced mixes I've uploaded on my MixCloud account here: https://www.mixcloud.com/joshcpld/ .

Due to the amount of data I worked with in this project (and the likelihood of copyright infringements) I haven't uploaded any of the music files themselves. However, if you're interested in looking at the scope of music in my dad's favourite music of all time you can look at the files in the documentation folder.
